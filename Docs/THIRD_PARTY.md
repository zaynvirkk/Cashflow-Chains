# Dependencies and original work

Unity 6000.3.26f1 Personal; Universal 2D template, URP 17.3.0, Input System 1.20.0, uGUI/TextMeshPro 2.0.0, Test Framework 1.6.0: Unity package licences recorded in their package directories and pinned in Packages/packages-lock.json. Pipeline 0.8.0-exp.1 (embedded verified local cache; 0.9 download required unavailable auth) is local editor automation only, not gameplay networking.

DejaVu Sans is bundled from the system font package; full attribution/licence in FONT_LICENSE.txt. Board icons, masks, panels and routes are original C# vector UI geometry in this project. No asset-store graphics, downloaded gameplay artwork or music. Audio/production asset sets are deferred until their gate.

No IAP, ads, external analytics, crash-upload or remote-content SDK has been added. Unity engine/template packages are retained and listed in manifest and lock. Unity Connect service m_Enabled flags disabled by project bootstrap. The template m_EngineDiagnosticsEnabled flag remains 1; actual engine diagnostic traffic has not been audited. Verify that engine setting and the final network inventory before release. No custom runtime network permission or gameplay network code.
