# Dependencies and original work

Unity 6000.3.26f1 Personal; Universal 2D template, URP 17.3.0, Input System 1.20.0, uGUI/TextMeshPro 2.0.0 and Test Framework 1.6.0. Package licenses are in the package directories; versions and transitive dependencies are pinned in Packages/packages-lock.json. Pipeline 0.8.0-exp.1 is embedded from the verified installed cache and is used for local Editor automation. Its optional player server is not configured/enabled in these builds; the package also contains an in-process console buffer.

Unity IAP 5.4.4 was installed using the Package Manager Client API. Configuration is absent in the local playtest edition, so checkout and restore fail closed. See DEPENDENCY_ADDITIONS.md for genuine billing prerequisites and privacy boundaries. No ads SDK, custom analytics uploader, crash uploader, account system or runtime content server was added. Unity Connect and engine diagnostic enable flags are disabled by the scene/bootstrap builder; this is configuration evidence, not a packet-capture audit of the engine or platform.

The initial building/object/location art is original SVG work rasterized by CairoSVG and remains preserved. Visual V2 uses project-specific generated painted environments and sprite atlases, plus original native material/particle rendering; see VisualV2/ASSET_PROVENANCE.md. Music and cues are original deterministic synthesis with no external recordings. The authoring tools use CairoSVG 2.9.1, NumPy 2.4.6 and Pillow 13.0.0 outside the runtime. See ASSET_PROVENANCE.md and ORIGINAL_ASSETS.json. DejaVu Sans, Sans Bold, Serif and Serif Bold use the included FONT_LICENSE.txt. No asset-store graphics or music.

Android's merged manifest includes INTERNET and ACCESS_NETWORK_STATE from the engine/SDK stack, com.android.vending.BILLING from native IAP, VIBRATE for optional 12 ms touch feedback, and the package-scoped DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION from AndroidX receiver protection. No microphone, camera, contacts, location or shared-storage permission is requested. Review captures use the app's own external files directory. Ordinary puzzles and saves work in airplane mode; genuine configured store operations require networking. Verify the final store privacy declarations against the exact release binary and enabled services before publication.


V2 visual/audio revision: painted environments and sprite atlases generated specifically for these projects with the built-in OpenAI image-generation tool; native material/particle rendering and original new stereo synthesis. See VisualV2/ASSET_PROVENANCE.md. Earlier vector source and synthesis remain preserved. No named inspiration-game assets or additional SDKs were imported.


Release tool: Google bundletool 1.18.3 (Apache-2.0), downloaded from https://github.com/google/bundletool/releases/tag/1.18.3 for local bundle validation. It is not shipped in the game. Android build tools and Unity are build-time dependencies. Unity Purchasing and service analytics packages are absent from this free release.


Production expansion restores Unity Purchasing 5.4.4 via Package Manager Client.Add (operator explicitly requested C12 monetization). Platform Google Play billing only, with real metadata/receipt validation. INTERNET and BILLING permissions support optional commerce; core gameplay remains offline. No ad SDK, Unity Analytics initialization, D2C payment provider or authentication login is configured. IAP 5.4+ SDK privacy still requires full review before publishing: https://docs.unity.com/en-us/iap/privacy-and-consent/overview . Prior free-only dependency statements are historical.
