# Local typography

Cashflow: Lilita One display/button lettering and Alegreya Sans body/bold. Black Bag: Cinzel Decorative Bold display and Crimson Text regular/bold body. DejaVu is the symbol fallback. Fonts are local TextMeshPro resources; no font request is made during play.

The original upstream font files are from the Google Fonts repository, with unmodified notices in Docs/Licenses:
- https://github.com/google/fonts/tree/main/ofl/lilitaone
- https://github.com/google/fonts/tree/main/ofl/alegreyasans
- https://github.com/google/fonts/tree/main/ofl/cinzeldecorative
- https://github.com/google/fonts/tree/main/ofl/crimsontext

The earlier Grenze Gotisch experiment is not the final Black Bag typeface. The reference's elegant engraved Roman lettering determined the Cinzel choice. All labels stay native and use a bounded fallback asset for symbols.
