# Game typography, revision 3

Cashflow display: Lilita One by Juan Montoreano. Black Bag display: Grenze Gotisch by the Grenze Gotisch Project Authors, static instance at weight650 from the original variable font. Body and bold: Alegreya Sans by its Project Authors. DejaVu remains a symbol fallback. All font licensing/copyright notices are copied verbatim in Docs/Licenses; upstream files from Google Fonts. No runtime font service or package.

Sources:
- https://github.com/google/fonts/tree/main/ofl/lilitaone
- https://github.com/google/fonts/tree/main/ofl/grenzegotisch
- https://github.com/google/fonts/tree/main/ofl/alegreyasans

The static instance changes only the variable weight, using fontTools. Font files are local Resources/Fonts/V3 assets; all gameplay text remains native TextMeshPro.
